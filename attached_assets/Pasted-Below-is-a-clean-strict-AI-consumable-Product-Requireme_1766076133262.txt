# PRODUCT REQUIREMENTS DOCUMENT (PRD)

**Project:** Equipment Management Web Application
**Version:** 1.0
**Target Output:** Fully functional web application
**Architecture:** React SPA + Node.js (Express) API + MySQL database

---

## 1. PRODUCT OVERVIEW

Build a single-page web application that allows users to manage equipment records.
The application must support full CRUD (Create, Read, Update, Delete) operations on equipment data using a REST API and a MySQL database.

The system is **internal-use**, does **not** require authentication, and prioritizes clean code, correctness, and maintainability.

---

## 2. FUNCTIONAL REQUIREMENTS

### 2.1 Core Features

The application MUST allow users to:

1. View all equipment in a table
2. Add new equipment
3. Edit existing equipment
4. Delete equipment

### 2.2 Equipment Attributes

Each equipment record MUST contain:

| Field             | Type      | Required | Notes                               |
| ----------------- | --------- | -------- | ----------------------------------- |
| id                | integer   | yes      | Auto-generated primary key          |
| name              | string    | yes      | Max 255 chars                       |
| type              | enum      | yes      | Machine, Vessel, Tank, Mixer        |
| status            | enum      | yes      | Active, Inactive, Under Maintenance |
| last_cleaned_date | date      | no       | Format YYYY-MM-DD                   |
| created_at        | timestamp | yes      | Auto-generated                      |
| updated_at        | timestamp | yes      | Auto-generated                      |

---

## 3. FRONTEND REQUIREMENTS

### 3.1 Technology

* React (Create React App or equivalent)
* JavaScript (no TypeScript required)
* Fetch API or Axios
* Basic CSS or Bootstrap
* No authentication
* No external UI frameworks required

### 3.2 UI Structure

The frontend MUST contain:

#### 3.2.1 Equipment Table

* Displays all equipment records
* Columns:

  * Name
  * Type
  * Status
  * Last Cleaned Date
  * Actions (Edit, Delete)
* Data fetched from backend API on page load

#### 3.2.2 Equipment Form

* Used for **Add** and **Edit**
* Fields:

  * Name (text input)
  * Type (dropdown)
  * Status (dropdown)
  * Last Cleaned Date (date picker)
* Submit button disabled while request is in progress

#### 3.2.3 User Feedback

* Show success message on successful create/update/delete
* Show error message on API failure or validation error

## 6. API SPECIFICATION

### Base URL

`/api`

---

### 6.1 GET /api/equipment

**Purpose:** Fetch all equipment

**Response (200):**

```json
{
  "data": [
    {
      "id": 1,
      "name": "Mixer A1",
      "type": "Mixer",
      "status": "Active",
      "last_cleaned_date": "2025-12-15",
      "created_at": "timestamp",
      "updated_at": "timestamp"
    }
  ]
}
```

---

### 6.2 POST /api/equipment

**Purpose:** Create new equipment

**Request Body:**

```json
{
  "name": "string",
  "type": "Machine|Vessel|Tank|Mixer",
  "status": "Active|Inactive|Under Maintenance",
  "last_cleaned_date": "YYYY-MM-DD"
}
```

**Response (201):**

```json
{
  "data": {
    "id": 2
  }
}
```

**Response (400):**

```json
{
  "error": "Validation failed"
}
```

---

### 6.3 PUT /api/equipment/:id

**Purpose:** Update existing equipment

**Request Body:** Same as POST (all fields optional but validated)

**Response (200):**

```json
{
  "data": "updated"
}
```

**Response (404):**

```json
{
  "error": "Equipment not found"
}
```

---

### 6.4 DELETE /api/equipment/:id

**Purpose:** Delete equipment

**Response (204):**
No content

**Response (404):**

```json
{
  "error": "Equipment not found"
}
```

## 7. DATABASE REQUIREMENTS (MYSQL)

### 7.1 Table Definition

```sql
CREATE TABLE equipment (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  type ENUM('Machine','Vessel','Tank','Mixer') NOT NULL,
  status ENUM('Active','Inactive','Under Maintenance') NOT NULL DEFAULT 'Active',
  last_cleaned_date DATE NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```
