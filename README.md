# Equipment Management System

A full-stack web application for managing industrial equipment with create, read, update, and delete (CRUD) operations. Built with React, TypeScript, Express.js, and MySQL.

## Features

- **Equipment Management**: Add, view, update, and delete equipment records
- **Type Classification**: Support for Machine, Vessel, Tank, and Mixer types
- **Status Tracking**: Track equipment status (Active, Inactive, Under Maintenance)
- **Last Cleaned Date**: Record when equipment was last cleaned
- **Responsive UI**: Built with React and Tailwind CSS
- **Input Validation**: Client and server-side validation with Zod and Express Validator
- **RESTful API**: Clean API endpoints for all CRUD operations

## Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/shreyasc84/equipment_management.git
cd equipment_management
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Set Up MySQL Database

Ensure MySQL is running, then create the database:

```bash
mysql -u root -pYourPassword < setup-db.sql
```

### 4. Configure Environment Variables

Create a `.env` file in the root directory:

```env
DATABASE_URL=mysql://root:Shresql@localhost:3306/equipment_app
```

**Note**: Update the username, password, and host as per your MySQL configuration.

### 5. Start the Development Server

```bash
npm run dev
```

The application will be available at **http://localhost:5000**

## API Endpoints

### GET /api/equipment
Fetch all equipment records

**Response:**
```json
{
  "data": [
    {
      "id": 1,
      "name": "Pump A",
      "type": "Machine",
      "status": "Active",
      "lastCleanedDate": "2025-12-18",
      "createdAt": "2025-12-18T10:00:00Z",
      "updatedAt": "2025-12-18T10:00:00Z"
    }
  ]
}
```

### POST /api/equipment
Create a new equipment record

**Request Body:**
```json
{
  "name": "Pump A",
  "type": "Machine",
  "status": "Active",
  "lastCleanedDate": "2025-12-18"
}
```

### PUT /api/equipment/:id
Update an equipment record

### DELETE /api/equipment/:id
Delete an equipment record

## Assumptions Made

1. **MySQL as Primary Database**: Used MySQL instead of PostgreSQL for better Windows compatibility.

2. **Single User Application**: The application does not include user authentication or multi-user support.

3. **Local Development**: The setup assumes local MySQL running on `localhost:3306`.

4. **Date Format**: Dates are stored as `YYYY-MM-DD` and handled as Date objects in the application.

5. **VARCHAR for Enums**: Type and Status fields use VARCHAR(100) instead of MySQL ENUM for flexibility.

6. **Auto-increment IDs**: Equipment IDs are auto-generated by MySQL.

7. **Timestamps**: Created and Updated timestamps are managed automatically by the database.

8. **No File Uploads**: The system doesn't support equipment image or document uploads.

9. **In-memory Validation**: All validation happens on the server; no client-side caching of validation rules.

10. **English Language Only**: The application is designed for English-only usage.

## Troubleshooting

### Port 5000 Already in Use


### MySQL Connection Error
- Verify MySQL is running: `mysql -u root -pYourPassword`
- Check `.env` file has correct DATABASE_URL
- Ensure database `equipment_app` exists
